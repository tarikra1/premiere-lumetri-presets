# Changelog

All notable changes to `premiere-lumetri-presets` are documented in this file.

## [1.0.0] - 2026-11-25

### Added
- Built-in calibrated Lumetri Color look registry (`editorial_teal`, `golden_hour`, `bright_tour`, `clean_studio`).
- Voice-aware background music ducking keyframe calculator (`compute_ducking_envelope`).
- ExtendScript (`.jsx`) generator, CLI (`lumetri-gen`), and GitHub Actions CI matrix.
