**Programmatic Lumetri Color look registry and voice-aware audio ducking ExtendScript (`.jsx`) generator for Adobe Premiere Pro.**

## Quickstart

```bash
pip install -e .
lumetri-gen list
lumetri-gen jsx editorial_teal --track 2 -o apply_grade.jsx
```
